An embedded storage engine for Rust and Python. Keys sort byte-wise, batches commit atomically and iterators seek, on a local disk or straight on S3, GCS or Azure. Every commit is a Lance version, so several processes can write at once and any version can be opened again.

The same store from Rust and Python

A database is a path or a URI. Writes are visible at once, logged locally before they return, and committed to storage in batches.

Guarantees, written down

  • A write survives a killed process: it is in a local write-ahead log before the call returns.
  • A WriteBatch is atomic, for readers and in storage.
  • Writers on several machines append without coordination; conflicting keys resolve by sequence.
  • Every commit is a version; tagged versions survive cleanup.
